# FMC-PC / rotation coverage paper: experiment source

This package combines the local RCBD-HAR training code with the corrected September 2026 REALDISP mechanism controls and WEAR rotation-only runner used for the current manuscript. It is source code, not a dataset or a collection of trained weights.

## Contents

- `src/rcbd_har/`: model, placement perturbations, training and evaluation.
- `scripts/`: data conversion, frozen REALDISP comparisons, WEAR grouped cross-validation, and analysis entry points.
- `configs/`: the experiment YAML files and the fixed WEAR participant folds.
- `profiles_mechanism_controls/`: frozen training-participant placement profiles. The empirical, corrected beta, and clipped profile SHA-256 values are checked by the REALDISP control runner.
- `tests/`: local unit and protocol tests, including `test_mechanism_controls.py`.
- `reference_results/`: compact summaries and protocol locks copied from the archived experiment outputs. These are references for checking values, not substitute model checkpoints.

The current paper's REALDISP comparison uses subjects 1–10 for training, 11–12 for development, and 13–17 for the released test scope; the valid-signal sensitivity scope excludes subject 13's all-zero Self record. The reported WEAR correction uses seeds 256 and 3407. Do not treat the older gain-plus-noise WEAR runs as a third rotation-only seed.

## Environment and data

Install with `python -m pip install -e .` in a Python environment with a suitable PyTorch/CUDA build. The original training used a CUDA GPU. Neither REALDISP nor WEAR raw data is included; obtain the public datasets separately under their respective licenses.

For REALDISP, `scripts/prepare_realdisp.py` converts the official subject logs to Ideal and Self manifests. Use four distal accelerometers, 50 Hz, 8 s windows, 0.5 s stride, and the `--exclude-null` option. The frozen REALDISP YAML files contain the original server manifest path under `data.manifest`; set that field to the newly prepared Ideal manifest before running on another machine. Set both command-line manifest arguments to the new Ideal and Self paths. A path-only YAML edit changes its SHA-256, so note the changed path in any new reproduction report.

For WEAR, `scripts/prepare_wear_official_csv.py` produces `data/wear/manifest.csv` from the official CSV records. `configs/wear_rcbd.yaml` expects that manifest at the relative path. Keep `configs/wear_paper_folds.json` unchanged for the manuscript's participant-disjoint split.

## Manuscript experiment entry points

Run the frozen original 2×2 REALDISP comparison:

```bash
python scripts/run_realdisp_fmc_pc_review_ablation.py \
  --placement-profile profiles_mechanism_controls/placement_profiles_subjects1_10.json \
  --ideal-manifest /path/to/manifest_ideal.csv \
  --self-manifest /path/to/manifest_self.csv \
  --output-root /path/to/realdisp_2x2 \
  --device cuda
```

Run the eight newer REALDISP cells (uniform 180°, beta pool, clipped empirical pool, gravity-matched generator; each with and without prediction consistency) at seeds 256, 3407, and 114514:

```bash
python scripts/run_realdisp_mechanism_controls.py \
  --ideal-manifest /path/to/manifest_ideal.csv \
  --self-manifest /path/to/manifest_self.csv \
  --output-root /path/to/realdisp_mechanism_controls \
  --device cuda
```

Run the corrected WEAR rotation-only FMC cells on the fixed three folds:

```bash
python scripts/run_wear_fmc_pc_cv_angle_only.py \
  --profile profiles_mechanism_controls/placement_profiles_subjects1_10.json \
  --methods fmc_no_pc fmc_pc \
  --seeds 256 3407 \
  --output /path/to/wear_angle_only \
  --device cuda
```

The archived WEAR Clean and uniform-rotation anchors are generated by `scripts/run_wear_fmc_pc_cv.py`; the corrected runner switches off empirical gain and noise for the FMC conditions only. Full raw per-run outputs and model checkpoints are **not** in this source package. The small summaries in `reference_results/` identify the reported values and the WEAR config/fold/profile hashes.

## Verification limits

This package has been assembled from the locally saved July base source plus the September correction files. Its Python files and protocol tests can be checked locally, but the complete GPU training has not been rerun from this newly assembled directory. Accordingly, the archived scores are historical experiment outputs, not scores generated anew by this ZIP. Paths in the frozen YAML files refer to the original server layout and require adaptation when used elsewhere.
